---

## ✨ Ключевые особенности

- 🐾 **Виртуальный питомец и кликер:** Кликайте по персонажу, зарабатывайте опыт (XP), повышайте уровень и следите за динамическими шкалами сытости, энергии и настроения.
- 💬 **Умный чат с локальным ИИ:** Полноценный диалог с моделью **Qwen 2.5 (7B)** через Ollama. Работает полностью локально, без интернета и подписок.
- 🎭 **Живая анимация по контексту:** Персонаж автоматически анализирует текст ответов нейросети и при упоминании ключевых слов (*«кушать», «спать», «танцевать»*) сам переключает соответствующие анимированные GIF-спрайты.
- 💾 **Автосохранение:** Весь прогресс, уровень, клики и текущее состояние питомца мгновенно сохраняются в локальный файл `save.json`.
- 🎨 **Стильный интерфейс:** Выдержанный в темных тонах интерфейс на PyQt6 с кастомными градиентными шкалами и плавающими анимациями сердечек.

---

## 🛠 Системные требования

- **ОС:** Windows 10 / 11
- **Python:** версия 3.10 или выше
- **Видеокарта (GPU):** Рекомендуется видеокарта с поддержкой CUDA (например, NVIDIA GTX 1070 с 8 ГБ VRAM и выше) для комфортного и быстрого ответа языковой модели Qwen 2.5.

## 📦 Инструкция по установке и запуску
Следуйте этой пошаговой инструкции, чтобы развернуть виртуального питомца на вашем компьютере (Windows).

**Шаг 1. Предварительные требования**
Убедитесь, что у вас на компьютере установлены:

Python (версии 3.10 или выше, скачайте с официального сайта python.org).

Git (опционально, для клонирования репозитория).

**Шаг 2. Загрузка проекта**
Скачайте исходный код проекта к себе на компьютер или клонируйте репозиторий через командную строку:

```Bash
git clone <ссылка-на-ваш-репозиторий>

cd GanyuGame\ V1
```
**Шаг 3. Установка и настройка локальной ИИ-модели (Ollama)**
Чтобы Гань Юй могла общаться с вами в чате, используется локальная нейросеть через Ollama:

Скачайте и установите Ollama с официального сайта (ollama.com).

Откройте терминал (PowerShell или командную строку) и загрузите модель qwen2.5:7b, выполнив команду:

```Bash
ollama run qwen2.5:7b
```
Дождитесь окончания загрузки. После этого модель будет запущена, а сервер Ollama останется работать в фоновом режиме на вашем ПК (127.0.0.1:11434).

**Шаг 4. Настройка виртуального окружения Python**
Рекомендуется установить все зависимости в изолированное виртуальное окружение:

Откройте терминал в папке проекта (GanyuGame V1).
Создайте виртуальное окружение:

```Bash
python -m venv .venv
```
Активируйте его (для Windows PowerShell):

```Bash
.venv\Scripts\Activate
```
**Шаг 5. Установка библиотек**
После активации виртуального окружения установите необходимые Python-пакеты (PyQt6 для интерфейса и Requests для связи с нейросетью):

```Bash
pip install PyQt6 requests
```
**Шаг 6. Запуск приложения**
Когда всё готово, запустите приложение командой:

```Bash
python main.py
```
После этого откроется главное окно программы с вашим питомцем и чатом!

## 🧠 Настройка характера (Лор персонажа)
Вы можете тонко настраивать манеру общения Гань Юй, её биографию и правила ответов. Для этого создайте в корне проекта текстовый файл ganyu_lore.txt и запишите туда её предысторию, привычки и особенности характера. Программа автоматически подгрузит этот файл и передаст его в качестве системного промпта нейросети.
